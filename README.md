# PassTheExam (정보보안기사 및 자격증 합격 전략 플랫폼)

> **정보보안기사(필기/실기)** 수험생을 위한 지능형 학습, CBT/실기 모의고사 풀이, AI 서술형 채점 및 합격 예측 웹 플랫폼입니다.  
> 추후 다양한 IT/국가기술자격증으로 확장 가능한 메타데이터 기반 프레임워크로 구축됩니다.

---

## 📌 주요 기능
1. **체계적 개념 학습**: 5대 보안 영역별 핵심 요약 및 관련 법령/치트시트 제공
2. **필기 CBT 모의고사**: 기출/예상 문제 풀이, 과목별 과락 방지 분석
3. **실기 단답/서술/실무형 대비**:
   - 실제 시험 답안지 형식 훈련
   - 필수 키워드 및 의미 유사도 기반 AI 서술형 자동 채점 & 첨삭
   - Snort 룰, iptables, 로그 분석 등 실무형 시나리오 시뮬레이션
4. **합격 예측 리포트**: 취약 단원 분석 및 목표 점수 달성 확률 진단
5. **확장형 아키텍처**: 타 자격증(정보처리기사, 빅데이터분석기사 등) 추가가 용이한 범용 스키마 및 엔진 설계

---

## 📂 프로젝트 구조 (예정)
```
pass_the_exam/
├── docs/                 # 종합 기획서 및 아키텍처 설계 문서
├── frontend/             # Next.js 14+ 기반 웹 프론트엔드 (CBT, 대시보드, 학습 UI)
├── backend/              # FastAPI / NestJS 기반 API 서버 및 AI 채점 엔진
└── data/                 # 자격증 메타데이터, 기출문제 및 루브릭 데이터셋
```
